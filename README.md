# Machine Learning Zoomcamp

This repository contains my homework assignments, notes, and projects completed during the [Machine Learning Zoomcamp](https://github.com/DataTalksClub/machine-learning-zoomcamp) course by DataTalksClub.

## 📂 Repository Structure

The repository is organized sequentially by module:

*   `01-intro`: Introduction to Machine Learning
*   `02-regression`: Linear Regression models
*   `03-classification`: Logistic Regression and Classification metrics
*   `04-evaluation`: Model evaluation and metrics
*   `05-deployment`: Model deployment (FastAPI, Docker)
*   `06-trees`: Decision Trees and Ensemble methods
*   `07-midterm-project`: End-to-end ML project (Energy Efficiency Prediction)

## 🛠️ Tech Stack

Throughout these modules and projects, I have utilized:
*   **Languages:** Python
*   **Data Manipulation:** Pandas, NumPy
*   **Machine Learning:** Scikit-Learn, XGBoost
*   **Deployment & Web:** FastAPI, Uvicorn
*   **Containerization:** Docker

## 🚀 Key Projects

*   **[Midterm Project - Energy Efficiency Prediction](./07-midterm-project)**:
    An end-to-end machine learning microservice that predicts the heating load of residential buildings based on architectural features. Built with XGBoost, deployed via FastAPI, and containerized with Docker.
